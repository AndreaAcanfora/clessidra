### Download

| | Desktop app | Command line |
| --- | --- | --- |
| **macOS** (Apple Silicon and Intel) | `clessidra_*_universal.dmg` | `clessidra-*-aarch64-apple-darwin.tar.gz` / `x86_64-apple-darwin` |
| **Windows** | `clessidra_*_x64-setup.exe` or `.msi` | `clessidra-*-x86_64-pc-windows-msvc.zip` |
| **Linux** | `.AppImage`, `.deb` or `.rpm` | `clessidra-*-x86_64-unknown-linux-gnu.tar.gz` |

The builds are not signed yet. On macOS, if the app is reported as damaged or from an unidentified
developer, move it to Applications and run `xattr -dr com.apple.quarantine /Applications/clessidra.app`.
On Windows, choose *More info* then *Run anyway* in the SmartScreen prompt.
